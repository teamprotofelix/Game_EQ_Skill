# SKILL CORE — 마리의 AI 심사품질 진단 아케이드

**생성형 AI · 스킬 지침 · KIPRIS Plus · 판본 복원 · OA/RD/RC 규칙 · 평가관 피드백**의 관계를 직접 조작하며 익히는 오프라인 HTML5 아케이드 교육 게임입니다.

## 실행 / GitHub Pages

1. ZIP 압축을 풉니다.
2. `index.html`을 Chrome, Edge, Firefox, Safari 등 브라우저에서 열면 오프라인으로 실행됩니다.
3. GitHub Pages에 호스팅하려면 압축 해제한 파일·`assets/` 폴더를 저장소 `main` 루트에 올리고 **Settings → Pages → Deploy from a branch → main / (root)** 를 선택합니다. 별도 서버, API 키, 환경변수, npm 설치가 필요하지 않습니다.

## 조작

- 키보드 **← / →** 또는 **A / D**: 데이터 게이트 선택
- **Space / Enter**: 현재 선택 게이트 스캔
- **1 / 2 / 3**: 해당 게이트 바로 선택
- 스마트폰·태블릿: 게이트 카드 터치 또는 하단 ◀ 스캔 ▶ 버튼
- 우측/상단 **시스템 지도**와 **학습 도감**에서 7단계 시스템 구조·규칙 참고

## Illustrated Edition (2026-10-30)

이번 개선판은 사용자와 함께 생성한 고해상도 원본 PNG를 전부 **WebP**로 최적화하여 실제 게임에 적용합니다. 원본 PNG는 배포하지 않습니다.

- 환경: 7개 게임 구역별 1600×900 WebP 배경과 챕터 이미지, 메뉴 배경
- 연출: 캔버스 스프라이트 시트(히로인 10 / 동행 로봇 8 / 적 16 / 보스 12 프레임), 포털·보상 아이템·반복 바닥 타일
- UI: 게이트마다 별도 수집 아이콘, 캐릭터가 등장하는 임무 안내, 지역 일러스트 패널, 작은 화면의 캐릭터 표시
- 실행: HTML + CSS + JavaScript로만 구성, 모든 시각 리소스는 WebP, 외부 CDN 불필요
- 점검: Node.js 문법 검사, Chromium HTML 인라인 렌더링에서 33/33 미션 완료, 데스크톱·모바일 레이아웃 및 자바스크립트 런타임 오류 확인. 현재 브라우저 관리 정책으로 직접 localhost/file URL 이동은 차단되어 실제 배포 URL의 방문 검증과 Android 실기기 검증은 수행하지 못함.

이미지 레이아웃용 파일과 실제 스프라이트 아틀라스는 `assets/`에 있습니다. 각 프레임은 가공된 WebP이며 원본 AI 생성 시트가 일부 겹쳐지는 영역에서는 아틀라스 경계가 완벽하지 않을 수 있습니다. 실제 심사품질의 법적 평가가 아닌 교육용 원리 게임입니다.
